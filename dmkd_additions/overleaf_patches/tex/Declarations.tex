\subsection*{Data Availability}
The code used in this research is publicly available on GitHub at \url{https://github.com/hjamet/LLM-Difficulty-Based-Recommendation}. The datasets used for difficulty estimation and text simplification are available on HuggingFace. The Tomplay dataset used for the recommendation system evaluation contains private user data and is not publicly shared to protect user privacy. Any requests for access to the private dataset should be directed to the corresponding author and will be considered on a case-by-case basis, subject to data protection regulations.
